# Bantul Poverty Clustering
Agglomerative Hierarchical Clustering analysis of poverty characteristics across subdistricts in Bantul Regency.

## Analysis
The analysis applies Agglomerative Hierarchical Clustering (AHC) to group subdistricts based on selected poverty-related indicators.
